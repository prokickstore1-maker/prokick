## 📌 Rincian Temuan & Solusi

### A-01 — [CRITICAL] Kontras Teks Gelap di Latar Gelap (Ghost Headers)
* **Lokasi:** `components/admin/product-manager.tsx:182-183`, `components/admin/settings-form.tsx:40-45`
* **Masalah:** Komponen root memakai `text-[#0C0A09]` dan header memakai `text-[#57534E]` di dalam layout yang berlatar `bg-[#09090B]`. Judul halaman "Produk" dan "Settings" menjadi teks hitam di atas kanvas hitam (100% tidak terbaca).
* **Fix (FIXED):** Diubah ke token kanonik `DESIGN.md`: teks utama `#FAFAFA`, teks sekunder `text-zinc-400`.

### A-02 — [CRITICAL] Tabel Terpotong di Layar HP (Horizontal Clipping)
* **Lokasi:** `components/admin/product-manager.tsx:310-334`
* **Masalah:** Elemen `<table>` 4 kolom dipaksakan di layar HP (<400px). Kolom pertama (nama jersey) terdorong ke kiri luar layar dan terpotong (hanya menyisakan suku kata "ue", "s Version"). Admin tidak bisa mengenali produk yang ingin diedit atau dihapus.
* **Fix (FIXED):** 
  * Mobile (`sm:hidden`): Kartu vertikal mandiri dengan thumbnail 56px, nama lengkap, badge liga, harga, dan tombol aksi `Edit` / `Hapus` dengan tap-target minimal 44px (`min-h-11`).
  * Desktop (`hidden sm:block`): Tabel dengan kontainer gelap `#121217` dan border `#27272A`.

### A-03 — [CRITICAL] Kontrol Stok Hilang dari Layar Mobile (Hidden Steppers)
* **Lokasi:** `components/admin/jersey-stock-table.tsx:79-95`
* **Masalah:** Tabel inventaris 6 kolom desktop membuat kolom matriks ukuran dan tombol tambah/kurang (`+` / `−`) terdorong jauh ke kanan luar viewport HP. Admin hanya melihat thumbnail dan ruang putih kosong tanpa bisa mengubah stok.
* **Fix (FIXED):**
  * Mobile (`sm:hidden`): Kartu jersey dengan ringkasan total stok, disertai grid 2 kolom berisi setiap ukuran (S, M, L, XL). Masing-masing ukuran memiliki tombol `+` (aksen volt `#E2F952`) dan `−` yang dapat langsung ditekan jempol.
  * Desktop (`hidden sm:block`): Tabel inventaris tetap tersedia.

### A-04 — [HIGH] Validasi Kaku Upload Foto Produk (800px Block)
* **Lokasi:** `components/admin/product-manager.tsx:90-99`
* **Masalah:** Validasi kaku sisi terpendek `Math.min(probe.width, probe.height) >= 800` langsung menolak foto produk yang diambil dari kamera HP atau WhatsApp (misal 600–750px), menghasilkan error *"minimal sisi 800px... Dilewati"*.
* **Fix (FIXED):**
  * Ambang batas diturunkan ke `300px` untuk menyaring file rusak saja.
  * Kompresi otomatis berbasis Canvas (`resizeToDataUrl`) tetap aktif untuk merampingkan gambar besar (>1600px) menjadi JPEG optimal saat disimpan tanpa membebani admin.

### A-05 — [HIGH] Input Running Banner Terjepit ("NEW SEASO")
* **Lokasi:** `components/admin/settings-form.tsx:69-73`
* **Masalah:** Label dan input berada di dalam container flex tanpa lebar penuh, menyebabkan input teks terhimpit di tengah dan teks terpotong.
* **Fix (FIXED):** Dipisahkan menjadi layout vertikal bersih (`space-y-1.5`) dengan `Input className="w-full"` membentang penuh 100%.

### A-06 — [MED] Inkonsistensi Tema Gelap vs Kartu Putih Silau (Frankenstein UI)
* **Lokasi:** `components/admin/**` (Product, Stock, Settings, Orders)
* **Masalah:** Header admin memakai tema gelap stadion `#121217` dengan aksen volt, namun isi halaman ditempel kartu putih silau `bg-white` dengan border abu-abu `#E5E5E5`.
* **Fix (FIXED):** Seluruh card, modal slip pembayaran, dan editor diselaraskan ke token `DESIGN.md`:
  * Surface: `#121217`
  * Surface elevated: `#181820`
  * Border: `#27272A`
  * Aksen tombol aksi: Volt `#E2F952` teks hitam `#09090B`.

### A-07 — [PENDING REVIEW] Ketiadaan Landing Dashboard di `/admin`
* **Lokasi:** `app/admin/(protected)/page.tsx:4`
* **Masalah:** Saat ini `/admin` langsung melakukan `redirect("/admin/orders")`. Admin yang membuka lewat HP langsung disambut daftar transaksi tanpa ada ringkasan operasional harian.
* **Rekomendasi Solusi:** Ganti redirect dengan **Halaman Dashboard Ringkasan (Mobile Command Center)** yang menampilkan:
  1. Status Cepat: Order Perlu Diproses, Order Dikirim, Jersey Stok Menipis (<3 pcs), dan Total Penjualan.
  2. Tombol Pintas: Tambah Produk, Cek Order, Kelola Stok, Pengaturan.
  3. 5 Pesanan Terakhir dengan tombol WhatsApp langsung.
